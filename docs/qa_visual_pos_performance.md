# QA Visual Pós-Performance (Obrigatório)

## Quando executar
Executar após concluir as melhorias de velocidade da pipeline.

## Objetivo
Validar qualidade visual e consistência final antes de fechar a rodada de otimização.

## Checklist mínimo por lote
- [ ] Quais imagens ficaram boas.
- [ ] Quais imagens ainda podem melhorar.
- [ ] Se as renomeações ficaram corretas.
- [ ] Se a joia ficou bem centralizada e bem posicionada.
- [ ] Se houve corte ruim, borda ruim ou composição estranha.

## Saída esperada
- Relatório de QA visual por lote.
- Lista de pendências objetivas para próxima iteração.
- Decisão de status do lote: `APROVADO` ou `REVISAR`.

## Regra de prioridade
Após performance estabilizada, esta etapa de QA visual passa a ter prioridade real no fluxo de trabalho.
